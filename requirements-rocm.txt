# Easiest: just run `./start.sh` (its first-run --setup installs everything,
# picking the ROCm torch automatically). This file is for a manual install.
#
# IMPORTANT: install the ROCm build of torch FIRST, from the AMD wheel index, so
# pip doesn't pull the CPU/CUDA torch from PyPI (PyPI's version is usually newer,
# so a plain `pip install torch` here would win and you'd lose the GPU). Then this
# file for the rest. Adjust rocm6.3 to your installed ROCm (see HOW_TO_RUN.md → AMD GPU):
#
#   pip install --index-url https://download.pytorch.org/whl/rocm6.3 torch torchvision
#   pip install -r requirements-rocm.txt
#
# (torch/torchvision are intentionally NOT listed below — they come from the ROCm
# index in the line above; listing them here would let PyPI override the ROCm build.)
